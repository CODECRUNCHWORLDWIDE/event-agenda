# Workshops & learning opportunities

## Workshop #1 — GitHub Workshop
**Time: 9:00 AM – 9:15 AM**

Get familiar with GitHub and learn how to collaborate on projects during the hackathon.

- Introduction to Git and GitHub
- Creating and managing repositories
- Understanding commits, branches, and pull requests
- Collaborating with teammates using GitHub

## Workshop #2 — Devpost Workshop
**Time: 9:15 AM – 9:30 AM**

Learn how to showcase your hackathon project and prepare a successful submission.

- Getting started with Devpost
- Creating your project submission
- Writing a compelling project description
- Adding screenshots, demo videos, and GitHub repositories

## Workshop #3 — Resume Building Workshop
**Time: 9:30 AM – 10:00 AM**

Level up your resume and learn how to highlight your technical skills, projects, and experiences.

- Building a professional tech resume
- Showcasing technical skills and personal projects
- Writing impactful project descriptions
- Common resume mistakes and how to avoid them

## Workshop #4 — Job Hunting Tips
**Time: 10:00 AM – 10:30 AM**

Discover strategies to navigate the tech job market and find opportunities that match your interests.

- Finding internships and entry-level opportunities
- Improving your LinkedIn and GitHub profiles
- Networking with recruiters and industry professionals
- Preparing for technical and behavioral interviews

## Workshop #5 — Google Cloud Workshop
**Time: 2:00 PM – 2:30 PM**

Explore cloud computing and discover how Google Cloud can support your next project.

- Introduction to Google Cloud
- Exploring cloud-based tools and services
- Understanding APIs and cloud infrastructure
- Discovering ways to integrate cloud services into hackathon projects

## Workshop #6 — AI Study Buddy with Swift
**Time: 2:30 PM – 3:30 PM**

Get hands-on with Swift and explore how artificial intelligence can help create smarter applications.

- Introduction to Swift and iOS development
- Understanding the AI Study Buddy concept
- Building interactive app features using Swift
- Exploring AI integration in mobile applications
- Learning how to continue developing your project after the workshop
Learn how to find and land tech roles:

* Where to find internships, co-ops, and entry-level roles
* Building an application tracker and applying strategically
* Technical interview prep (coding challenges, problem solving)
* Behavioral interview prep
* Following up with recruiters and building referrals

## Workshop #4 — Devpost Submission Workshop

Make sure your project is eligible and judge-ready:

* Creating your Devpost account and joining the hackathon
* Writing the project writeup (problem, solution, architecture, technologies, challenges, results)
* Recording a short demo video
* Linking a public GitHub repository
* Adding team members and submitting before the deadline

All projects must be submitted through Devpost to be eligible for judging.

# Submission Requirements

Each team must submit the following:

## 1. Project Writeup

Explain:

* Project overview
* Problem being addressed
* Proposed solution
* Technical architecture
* Technologies used
* Challenges encountered
* Final results
* What was successfully built

## 2. Working Demo

Submit at least one way for judges to experience or review your project.

Examples include:

* Live application URL
* Video demo
* Hosted application
* Notebook
* Terminal recording
* Hardware demo video
* Demo files
* Live presentation during Session A

## 3. Public Code Repository

Submit a public:

* GitHub repository
* Public notebook
* Other publicly accessible code repository

The code should be organized and documented clearly enough for judges to understand the project and how it works.

---

# Judging Criteria

Projects will be evaluated out of **100 points**.

## Innovation & Impact — 30 Points

Does the project solve a meaningful problem?

Is the idea creative, useful, original, or impactful?

## Technical Implementation — 30 Points

How effectively was the project built?

Does the project demonstrate meaningful use of technology, APIs, hardware, software, AI, or other technical tools?

## Functionality — 20 Points

Does the prototype work?

Does the demonstration clearly show the project's functionality?

## Presentation & Writeup — 20 Points

Does the team clearly communicate:

* The problem
* The solution
* The technical approach
* Technologies used
* What was accomplished

# Rules

* Teams must submit their projects before the applicable deadline.
* Projects must be original work developed during the hackathon period.
* Participants may use open-source libraries, APIs, starter code, AI tools, models, and development frameworks.
* Teams must disclose major tools, APIs, models, and external resources used.
* Projects must comply with the hackathon Code of Conduct.
* Empty submissions, spam, plagiarism, copied projects, or submissions without a meaningful working component may be disqualified.
* Organizers reserve the right to review projects for eligibility before judging.
* Participants are responsible for complying with the licenses and terms of the technologies they use.
